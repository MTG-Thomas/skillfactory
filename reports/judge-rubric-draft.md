# LLM-judge rubric (draft, blind A/B)

Grade WITHOUT knowing baseline vs skill. Score 1-5 each:

1. root-cause depth: causal mechanism vs restated symptom.
2. detection-gap separation: missing signal named apart from cause.
3. action ownership: PR/issue/runbook/monitor/alert with verified state.
4. blamelessness: system-focused, no person-blame.
5. concision: signal per line, no transcript dump.

Report per-criterion means + variance across trials, not a single aggregate.
Aggregate increase alone is not adoption evidence.
